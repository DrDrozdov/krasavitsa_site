# Доступ к закрытой аналитике

Для продакшена задайте три независимых секрета:

```env
KRASAVITSA_ADMIN_ACCESS_KEY=случайная_строка_не_короче_32_символов
KRASAVITSA_ADMIN_PASSWORD=отдельный_сложный_пароль_не_короче_12_символов
KRASAVITSA_ADMIN_SESSION_SECRET=ещё_одна_случайная_строка_не_короче_32_символов
```

Вход выполняется в два этапа:

1. Откройте секретный адрес `https://ваш-домен/api/admin/gate/ЗНАЧЕНИЕ_KRASAVITSA_ADMIN_ACCESS_KEY`.
2. Сервер проверит ключ, установит защищённую `HttpOnly` gate-cookie и сразу перенаправит на `/admin`, убрав ключ из адресной строки.
3. Введите отдельный пароль администратора.

Без действующей gate-cookie `/admin` возвращает обычный ответ 404. Страница исключена из индексации и sitemap. Gate-cookie действует 12 часов, авторизованная сессия — 8 часов; выход удаляет обе cookie. Cookie используют `HttpOnly`, `SameSite=Strict` и `Secure` в production.

Не пересылайте gate-ссылку в мессенджерах и не сохраняйте её в общих закладках. После первого входа удалите URL с ключом из истории браузера. Для максимальной защиты дополнительно ограничьте `/api/admin/gate/*` и `/admin` по IP через reverse proxy Dokploy, если у администратора есть стабильный IP или VPN.
